MIRA-01XX (MADDY Sound Source)

- 10 4OP FM - 20 2OP FM (OPM, OPN, OPL, MADDY INST.) (Only one at a time)
- 1-8 8BIT WAVETABLE/NOISE GENERATOR (512x256 Wave Length) (SID-like Filters)
- 4-32 1-16BIT PCM, DPCM, ADPCM (No Interpolation, Linear)

------------------------------------------------------------------------------------------------------

MADDY Project Files (.mdp, Music Device Project)

HEADER (not really): Includes song info (title, album,

/=|==GLOBAL REGISTERS==|=\



ADDR 0x0000 (STATUS/DATA REGISTER)
|0|TIMER 2 RESET
|1|TIMER 1 RESET
|2|TIMER 2 START
|3|TIMER 1 START
|4|TIMER 2 FLAG
|5|TIMER 1 FLAG
|6|IRQ FLAG
|7|---

//Side Note: These 2 addresses should control the BPM

ADDR 0x0001 (TIMER 1)
|0-7|TIMER 1 COUNTER (80 Nanosec. resolution)

ADDR 0x0002 (TIMER 2)
|0-7|TIMER 2 COUNTER (320 Nanosec. resolution)

ADDR 0x0003 (GLOBAL SOUND CONTROL 1)

//Side Note: Wavetables should always be 512x256 (Width x Height) in size,
	if you want smaller wave sizes, do it in software, just a heads up,
	it's not gonna make the RAM usage any smaller, only the storage will.

//Side Note: Sample channel amount should go up or down by 8CH per bit, if
	you need to play CD Audio, go do so on the first enabled channels via
	software and constant write/reading, like with SB16's DMA sampling or
	the PSX-SPU.

//Side Note: This disables certain features to remain compatible with
	certain chips. There can only be 1 FM inst. type per mode. It would
	have been AWESOME to use different YAMAHA sound sources, but i
	personally want it to be as compact as possible. Every byte 
	counts, y'know?

|0-1|FM Inst Mode (00-MADDY [DEFAULT], 01-OPM, 10-OPN, 11-OPL)
|2-4|Wavetable Channel Number (000-1CH [DEFAULT], 001-2CH... 111-8CH) 
|5-7|Sample Channel Number (000-4CH [DEFAULT], 001-8CH... 111-32CH)

ADDR 0x0004 (GLOBAL SOUND CONTROL 2 - 4OP FM MIX 1)
|0|Sample Interpolation (00-None [DEFAULT], 01-Linear)
|1|---
|2|CH-01 OP00-03
|3|CH-02 OP04-07
|4|CH-03 OP08-0B
|5|CH-04 OP0C-0F
|6|CH-05 OP10-13
|7|CH-06 OP14-17

ADDR 0x0005 (4OP FM MIX 2 - GLOBAL SOUND CONTROL 3)
|0|CH-07 OP18-1B
|1|CH-08 OP1C-1F
|2|CH-09 OP20-23
|3|CH-10 OP24-27
|4|---
|5-7|ExtCH3+9+15 MODE (000-Normal, 100-ExtCH3, 010-ExtCH9... 111-ExtCH3+9+15)



/=|==FM SYNTH REGISTERS==|=\



//Side Note: When using 2-OP mode, bit 2 has no effect.

ADDR 0x0006-0x001A (MADDY FM INST. CONTROL)
|0-2|ALGORITHM (CONTAINS OPN/OPM ALGORITHMS, SAME ORDERS, SAME THING)
|3-5|OP1 Feedback (000=0 FEEDBACK, 001=1 FEEDBACK... 111=7 FEEDBACK)
|6|MADDY OP Type (0=4OP [DEFAULT], 1=2OP)
|7|LFO ENABLE

//Side Note: Every step is 0.75dB quieter than the last
	(it should also be logarithmic, like a proper FM chip).

//Side Note: When using 2-OP mode, OP. 3-4 do nothing but are still stored.

ADDR 0x001B-0x0039 (OP. 1-4 TOTAL LEVEL + AM)
|0-5|VOLUME/TOTAL LEVEL
|6|VOLUME/TOTAL LEVEL
|7|AM ENABLE

//Side Note: Works in the same way as the NDS stereo panning,
	0 is center, and either extreme of this signed value
	should move to one speaker or the other smoothly.

ADDR 0x003A-0x004E (FM SIGNED STEREO PANNING)
|0-6|PANNING VALUE
|7|SIGN FLIP (0=Left, 1=Right)

ADDR 0x004F-0x0077 (OP. 1-4 WAVE+OCTAVE)
|0-3|Octave Multiplier (0000=Half Octave, 0001=1 Octave... 1111=16 Octaves)
|4|Waveform Bank (0xxx=OPL Series Waveforms, 1xxx=Custom Waveforms (MADDY) )
|5-7|Waveform Selection (x000-x011=OPL2/Custom Bank 1, x100-x111=OPL3/Custom Bank 2)

ADDR 0x0078-0x008C (FM-AM SENSITIVITY)
|0-2|FM SENSITIVITY
|3-4|AM SENSITIVITY
|5-6|LFO WAVE
|7|---

ADDR 0x008D-0x00A1 (LFO SPEED)
|0-2|LFO SPEED 0-7
|3-7|LFO SPEED 8-255

//Side Note: SSG-EG is only for OPN Mode and should work
	just the same as a real OPN series chip.

ADDR 0x00A2-0x00CA (OP. 1-4 ATTACK RATE + RATE SCALING + SSG-EG ENABLE)
|0-3|ATTACK RATE
|4|ATTACK RATE EXTRA (OPN/OPM/MADDY)
|5|SSG-EG ENABLE
|6-7|RATE SCALING

ADDR 0x00CB-0x00F3 (OP. 1-4 DECAY RATE + DETUNE 1)
|0-3|DECAY RATE
|4|DECAY RATE EXTRA
|5-7|DETUNE 1

//Side Note: Only works when SSG-EG is enabled (see prev. note)

ADDR 0x00F4-0x011C (OP. 1-4 SUSTAIN RATE + SSG-EG WAVEFORM)
|0-4|SUSTAIN RATE
|5-7|SSG-EG WAVEFORM

ADDR 0x011D-0x0145 (OP. 1-4 RELEASE RATE + SUSTAIN LEVEL)
|0-3|RELEASE RATE
|4-7|SUSTAIN LEVEL

//Side Note: This applies to every single voice in this chip,
	including the OPN ExtCH. modes and even the WSG + PCM

ADDR 0x0146-0x015A (NOTE FREQUENCY LOW)
|0-7|FREQUENCY

//Side Note: Aux. Output sends the digital audio to a different
	pair of stereophonic outputs, they could be used for rear
	speakers, but i planned to hook it up to a Reverb IC, and
	send it to the same analog output... the frontal speakers
	TRS jack.

ADDR 0x015B-0x016F (NOTE FREQUENCY HIGH + NOTE ON SWITCH + AUX. OUTPUT SWITCH)
|0-2|FREQUENCY
|3-5|BLOCK/OCTAVE
|6|NOTE ON
|7|AUX. OUTPUT (0=Main Output (Default), 1=Aux. Output)

//Side Note: What a waste of registers? Not Anymore!
	This baby can use up to 64 wavetables now! Have
	fun with your custom Waveforms!

ADDR 0x0170-0x0198 (OP. 1-4 DETUNE 2 + CUSTOM WAVE SELECTION)
|0-1|DETUNE 2
|2-7|CUSTOM WAVE ADDRESS



/=|==WSG + PCM REGISTERS==|=\



//Side Note: Both sound types have the same volume + panning
	levels, so naturally, i grouped them together.

	Noise only works on WSG, it has no effect on PCM.

	See ADDR 0x0034-0x004E's side note to know how this
	panning system works.

ADDR 0x0199-0x01C1 (WSG/PCM SIGNED STEREO PANNING + NOISE TOGGLE)
|0-5|PANNING VALUE
|6|SIGN FLIP
|7|NOISE TOGGLE (0=Noise Off, 1=Noise On)

//Side Note: Ring Mod. only connects to the next voice, if it's
	the last channel, it loops back to the 1st, if it's a
	Noise Ch. it skips to the next one and uses it.

	Sync. and Ring Mod. work the same, but only applies to WSG.

	Pitch Mod. works like on the SNES, but only on PCM.

ADDR 0x01C2-0x01EA (WSG/PCM VOLUME + RING/PITCH + SYNC)
|0-5|VOLUME LEVEL
|6|RING/PITCH MOD.
|7|SYNC NEXT VOICE

//Side Note: SID-Like Filter settings applies to
	individual voices, unlike the OG SID chip,
	which does it to all 3 of them. WSG only.

	Noise + Waveform AM should work like the AY
	chip's Tone/Envelope + Noise, but outputted
	like the high pitched buzz of the N163, it
	should output noise in-between DC offset, i meant

ADDR 0x01EB-0x01F2 (WSG SID-LIKE FILTER CONTROL 1 + NOISE SAMPLE MODE)
|0|HIGH PASS
|1|BAND PASS
|2|LOW PASS
|3|NOISE SAMPLE MODE (0=Noise only, 1=Noise + Waveform AM)
|4-7|FILTER RESONANCE 1

ADDR 0x01F3-0x01FB (WSG FILTER CUTOFF LOW-BYTE + WSG FURNACE SYNTH CH. 0-7)
|0-3|FILTER CUTOFF 1
|4-6|UNI MIX MODE (0000=Disable, 0xxx=SINGLE WAVE SYNTH)
|7|DUO MIX MODE (1xxx=DUAL WAVE SYNTH)

ADDR 0x01FC-0x0204 (WSG FILTER CUTOFF HIGH-BYTE)
|0-7|FILTER CUTOFF 2

ADDR 0x0205-0x020D (WSG FILTER CONTROL 2 / RESONANCE HIGH BYTE)
|0-7|FILTER RESONANCE 2

ADDR 0x020E-0x0216 (WSG FILTER VOLUME)
|0-7|FILTER VOLUME

//Side Note: PCM Drivers should convert to only using
	low byte when on an 8 bit (PC-XT) ISA bus

ADDR 0x0217-0x0237 (PCM BITBANG LOW BYTE)
|0-7|PCM DATA 1-8 BITS

//Side Note: Only available on a 16 bit (PC-AT) ISA bus or higher

ADDR 0x0238-0x0258 (PCM BITBANG HIGH BYTE)
|0-7|PCM DATA 9-16 BITS

//Side Note: There can only be 2 Noise Channels playing at a time

	DISCLAIMER: DO NOT EDIT LFSR REGISTERS MANUALLY!!! THE CHIP
	WILL USE THEM AUTOMATICALLY, CHANGING IT WILL ONLY BREAK IT!!!

ADDR 0x0239 (NOISE LFSR 1 LOW)
|0-7|NOISE LFSR 1 LOW

ADDR 0x023A (NOISE LFSR 1 HIGH)
|0-6|NOISE LFSR 1 HIGH
|7|---

ADDR 0x023B (NOISE LFSR 2 LOW)
|0-7|NOISE LFSR 2 LOW

ADDR 0x023C (NOISE LFSR 2 HIGH)
|0-6|NOISE LFSR 2 HIGH
|7|---

//Side Note: This is a hardware implementation of Furnace's
	Software WSG Synth feature, and should be treated as such
	when adding this chip to a Furnace fork, sneakily replace
	Furnace's Wave Synth with this one, no one should notice
	that it works different until they look inside the code /
	at the registers of the chip.

ADDR 0x023D-0x0245 (WSG SYNTH UPDATE RATE CH. 0-7)
|0-7|SYNTH UPDATE RATE

ADDR 0x0246-0x024E (WSG SYNTH SPEED CH. 0-7)
|0-7|SYNTH SPEED

ADDR 0x024F-0x0257 (WSG SYNTH AMOUNT CH. 0-7)
|0-7|SYNTH AMOUNT

//Side Note: This address is only for WSG Phase Mod.

ADDR 0x0258-0x0260 (WSG SYNTH POWER CH. 0-7)
|0-7|SYNTH POWER

//Side Note: Notice how it's only 7 bits? that because
	the Wavetable RAM only occupies 64K of space
	out of the 128MiB of max sample data available
	on the sound card's DDR3 SODIMM RAM socket.

	Also, the Wavetables only occupy 512B each if
	that wasn't obvious before.

ADDR 0x261-0x0269 (WSG SYNTH WAVE 1 / WSG WAVE SELECTION CH. 0-7)
|0-6|WAVE 1 ADDRESS
|7|---

//Side Note: This is only for Dual Wave Synth

ADDR 0x026A-0x0272 (WSG SYNTH WAVE 2 CH. 0-7)
|0-6|WAVE 2 ADDRESS
|7|---
